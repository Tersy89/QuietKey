Implemented changes:
- Restore release 1's standard DecoratedBarcodeView/default TextureView/framing and
  normal periodic AUTO autofocus. Remove forced SurfaceView/FitCenter/full-frame/
  continuous-focus configuration. Retain QR-only normal/inverted decoding.
- No timed code cycling and no automatic camera switching. Original scanner first;
  More → Try other scanner explicitly chooses CameraX. Light/Restart remain in More.
- Each new unique code shows Code scanned and pauses camera/decoding. The user taps
  Next code on the showing phone, then Scan next code on the scanning phone.
  Duplicates do not advance progress; other codes are gated while success is showing.
  The last Continue/Join group action returns the packet for normal verification.
- Non-floating full-screen QrTransferDialog, width-based square QR/camera area,
  short instructions above the code, one primary action, extra controls under More.
  No weighted image squeezed by captions/buttons. Separate Swap phones/finish pages.
- Invite opens scanning directly. Joiner shows request codes; owner scans/confirms
  Invite; joiner explicitly swaps to scanning the owner's invitation. No reverse invite.
- Saved invitation recovery, used-request protection, Start again and recipient-bound
  cryptography remain. Copy/Paste remains in the request/invitation paths; optional
  confirmation scanning has no mismatched invitation-paste action.
- Guide/design/security/testing notes describe the implemented manual workflow.
