Implemented:
- Groups Join/Invite chooser: USB cable (preferred), Personal hotspot, QR fallback.
  Saved QR grants/confirmation moved inside the invitation method chooser.
- Actual AOA phone-to-phone host/accessory adapter. USB role independent of owner role;
  Android permissions, re-enumeration, only AOA data endpoints, no ADB/debugging/computer.
  16-KiB accessory input buffering and bounded writes preserve logical USB packets.
- Package-scoped mutable USB permission PendingIntent with random action, nonexported
  receiver, manager permission recheck and cancellation on close. Corrected immutable
  callbacks before release: Android would otherwise discard grant/device result extras.
- Local hotspot TCP listener on selected private interface, literal RFC1918 addresses only;
  endpoints use getByAddress without DNS. Client explicitly binds a non-VPN Wi-Fi Network
  for No-Internet hotspots. Android Settings configures hotspot/association; no discovery.
- Random 100-bit temporary code protects hotspot frames with AES-GCM. No code/key saving,
  logging/autocopy. Strict bounded ordered framing, five failed initial connections,
  ten-second initial reads, five-minute overall deadline and closing on cancel/lock/exit.
- Unchanged signed QKJ1, recipient-encrypted QKG2 and QKA1. Explicit owner admission and
  recipient confirmation; all group details/secret/public keys import together. Automatic
  verified receipt marks Joined/cleans pending cache. Private identity keys never transfer.
- Pending owner grant can remain Invited after interrupted/declined recipient import;
  remove it or retry a fresh request. A committed group stays saved after lost confirmation.
  Cancelled approvals clear uncommitted material and cannot show late stale consent.
- Secure full-screen scrollable USB/hotspot windows, compact waiting/success, readable
  two-line code, keyboard handling and updated device guide. SYSTEM_DESIGN/README/security/
  phone-testing docs maintained. No message/file crypto or QR camera changes.
